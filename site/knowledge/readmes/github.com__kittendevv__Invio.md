If you want slim, easy to learn invoicing software that can still generate invoices in the formats used by several countries¹, Invio might be what you're looking for.

These are the supported formats as of the latest version

- **Factur-X / ZUGFeRD 2.2** (BASIC profile)
- **FatturaPA** (Italian electronic invoice, based on PA.004.001.03)
- **UBL 2.1** (PEPPOL BIS Billing 3.0)
